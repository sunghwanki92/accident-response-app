# 교통사고 대응

[휴대폰에서 바로 열기](https://accident-response-app.vercel.app/) · 로그인 필요 없음

사고 직후에는 긴 설명 대신 **안전 확인 → 보험사 연락 → 아는 것만 기록** 순서로 진행합니다. 다친 사람은 119, 경찰 도움이 필요하면 112 전화 화면으로 연결합니다. 실제 전화·문자 발송은 휴대폰에서 사용자가 진행합니다.

- 기본 안내, 기록, 복사, QR, 서류 기능은 무료입니다.
- 간단 기록은 장소·상대 차량·상황 중 아는 것 하나만 적어 저장할 수 있습니다. 상세 입력은 나중에 이어서 합니다.
- 기록은 현재 기기·브라우저에 저장되며 다른 기기와 자동 동기화되지 않습니다. 중요한 기록은 설정에서 백업하세요.
- 사진·영상 첨부는 현재 화면의 미리보기와 선택한 AI 분석용입니다. 원본 파일은 기록·백업에 포함되지 않습니다.
- QR은 기기 안에서 생성합니다. 당사자 개인정보가 있으므로 공개 배포하지 마세요. 앱 자체를 배포할 때는 위의 깨끗한 주소를 보내세요.
- AI는 본인 Gemini API 키로 선택 사용합니다. 분석 전에 전송 확인을 받으며 키·내용·사진/서류는 서비스 서버를 거쳐 Google에 전달됩니다. Google의 요금·이용 한도가 적용됩니다.
- API 키는 백업·복원에 포함하지 않습니다. 오래된 백업에 키가 있어도 가져오지 않습니다. 이미 외부에 공유한 과거 백업의 키는 제공자에서 폐기·재발급해야 합니다.
- AI는 실시간 웹 검색을 수행하지 않으며, 과실·법률·합의금은 참고 의견입니다.

안전 안내 출처: [손해보험협회 교통사고 대응요령](https://accident.knia.or.kr/fault-ratio), 2026-11-05 확인. 문구는 이 앱에 맞게 새로 요약했으며 공식 기관 앱이 아닙니다.

## 개발·검증

정적 파일은 로컬 HTTP 서버로 확인합니다. 서버 API는 Vercel의 `api/ai.js`입니다. 환경변수 `GEMINI_MODEL`을 지정하지 않으면 `gemini-2.5-flash`를 사용합니다. 공용 서버 API 키는 사용하지 않습니다.

```
npm test
```
